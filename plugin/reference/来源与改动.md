## 直接复用关系

- `plugin/src/main.js` 是最小入口，直接加载 `plugin/reference/main.js` 的默认导出。
- `web/webpack.obsidian.js` 把 `@` 解析到 `plugin/reference/src`，把 `simple-mind-map` 解析到当前仓库的 fork；参考 Vue 编辑器、Obsidian 菜单、命令、设置页和 Markdown 后处理流程均从 `plugin/reference/` 进入构建。
- `plugin/reference/SmmEditView.js` 承载 `TextFileView`、导图实例、当前文件生命周期和参考插件的 `$obsidianAPI` 方向。
- `.smm.md` 的严格解析、序列化和保存保护分别复用 `plugin/src/document/format.js`、`plugin/src/document/save.js`；图片和独立 SVG 落库复用 `plugin/src/assets.js`。

本地比较的结果仅用于审查复制范围：公开 `src/` 快照约 354 个文件，当前 `plugin/reference/` 的同路径文件约 345 个，其中 326 个字节一致，19 个文件有必要的标识、安全或引擎接口适配；项目元数据和构建配置没有复制。这个统计不是“与本地 0.2.12 完全一致”的证明。

## 已确认的本地适配

1. 视图类型改为 `personal-mindmap`；文件仍使用参考设计的 `.smm.md` 外壳和 `simplemindmap` 标签。
2. 参考源码的插件 ID 相关去重键改为使用 `this.manifest.id`，避免个人插件与其他实例共享硬编码 ID。
3. 首次使用引导默认关闭，设置初始化和新建文件失败会通过 Obsidian 提示报告，不静默吞掉入口错误。
4. 图床设置固定为 `useImgHosting: false`，设置页不提供图床配置；不接入 AI、OAuth/账号、VIP、云服务或联网协作。参考 UI 中遗留的通用文案或服务入口不属于本插件支持范围，不能据此宣称已提供这些服务。
5. `SmmEditView` 严格通过 `parseDocument()` 校验文件，损坏或非本格式内容不会覆盖当前原文；保存通过 `SaveCoordinator` 和 `vault.process()` 比较预期原文，冲突、删除和关闭失败走保护/恢复副本路径。
6. 自动保存沿用参考编辑器的数据快照流程：默认 5 秒只更新 `.smm.md` 数据；手动“保存并更新图像”才导出并写入独立 SVG 或内嵌 SVG。不能把自动保存描述为每 5 秒自动重生成 SVG。
7. `AssetStore` 拒绝库外绝对路径和 `..`，对不在 Vault 索引中的隐藏目录使用 adapter 检查，避免重复建目录；文件冲突不覆盖既有附件，独立 SVG 按源文件目录保持稳定且不碰撞。`AssetStore` 本身不扫描或清理旧资产；Markdown 后处理只更新缓存，不盲目删除或重命名其他 SVG 资产。

## 有意不包含的能力

- 不兼容本项目旧版 `.mindmap.md` 文件，不读取 CMBK 插件的 `data.json`，也不承诺自动迁移旧数据；当前没有需要保留的旧真实数据。
- 不声称实现公开源码之外的本地 0.2.12 新功能、闭源多根节点、AI、账号/VIP、图床/云端服务或 `smm` Markdown 代码块渲染。
- CMBK 参考目录只读；验收必须使用隔离库，不能同时让两个插件接管同一个 `.smm.md` 文件。

修改参考源码前，应先在本文件保留固定提交信息，并通过逐文件 diff 说明原因；优先使用可读源码。仅源码缺少的 TXT 解析适配从本地参考 main.js 的 06d0 模块移植至 src/utils/txt.js，来源文件 SHA256 为 a47b54515e981ee04eccaf3651f8214dc91641f502a9eb8a05e2482aab393c62。

提交前仅规范了参考 iconfont.css 的文件末尾空行和 Sidebar.vue 的一处空白行，避免 Git 差异检查报空白错误；不改变组件逻辑或样式规则。
