## 边界和未验证项

- 公开源码与本地安装版 0.2.12 不完全等同；不承诺全部后续功能。AI、账号、VIP、图床、云服务、自由多根节点及 `smm` 代码块不在本版范围。
- 沿用参考源码的完整编辑入口，但未穷举每个主题、拖拽、全部导入/导出格式、每个设置、真实打印、同文件分屏及第三方插件组合。
- 导出图像内容和预览已验证；原生下载对话框及所有二进制格式没有逐项人工验收。
- 非 Windows 系统、移动端、独立窗口、超大导图和断电/强杀进程恢复未验证。
- 为避免误删，派生 SVG 不自动清理；重命名或删除导图后可能留下旧 SVG。
- 构建复用旧上游工具链，npm 仍提示其历史 Node 引擎声明不匹配；本轮构建和必要测试已在上述环境通过，没有进行无关依赖升级。
