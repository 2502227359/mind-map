# 0.4.0 扩展格式移植

沿用 0.3.0 的导入导出界面、文件保存方式及宿主 API；不新增依赖，不改导图权威数据格式，不修改上一轮范围外代码。

| 功能 | 实现与调用点 | 验收条件 |
| --- | --- | --- |
| HTML 导出 | 现有 SVG 导出 → 自包含 HTML → 原导出菜单 | 可离线打开，库内图片内嵌，标题和属性转义；明确为静态预览 |
| Mermaid 导出 | 当前节点树 → mindmap 文本 → 原导出菜单 | 层级/顺序正确，重名节点不合并，中文、括号、引号、换行等不破坏语法；由 Obsidian 实际解析 |
| OPML 导出 | 当前节点树 → xml-js → 原导出菜单 | 文本、链接、备注及层级可往返，特殊字符转义正确 |
| OPML 导入 | 原文件选择/拖入 → 完整解析校验 → setData | 单根/多根可读；损坏文件、空大纲和 DTD 拒绝；失败时当前导图不变 |
| 构建与部署 | 原构建流程、隔离库、CMBK | 原有回归通过；集中实测；备份后安装，哈希/版本/错误检查一致 |

导出保护：HTML 采用严格图片转换，加载失败直接结束并报错；背景图失败不再留下挂起的 Promise。SVG 标题转义后才插入。Mermaid/OPML 遇游离树时拒绝导出并提示完整格式，OPML 遇 XML 1.0 禁止字符也拒绝写出。

边界：HTML 为静态图像预览，不提供交互编辑；Mermaid/OPML 是结构交换，不能保存全部节点样式、图片、附件或关联线，完整备份继续使用 SMM/JSON。不接入账号、VIP 验证、AI 或云服务。

动量、额外形状、自动对齐、懒加载、手绘、右鱼骨/表格、多根等另批处理；本轮不把安装包里存在的未公开增强实现冒充已移植的公开源码。FreeMind/XLSX 导入导出继续留在差异清单。

必要回归只覆盖格式转换和真实接口风险；最终通过数量、运行记录和未穷举范围写入《验收记录》。

实施状态：本批四项功能已接通并完成代表性验收；30 项必要回归通过，构建已安装到 CMBK 0.4.0。具体证据与剩余范围见 [验收记录](验收记录.md)。源码纳入 0.4.0 交付提交，提交及远端发布状态以 Git 记录为准。

格式依据：[OPML 2.0](https://opml.org/spec2.opml)、[Mermaid mindmap](https://mermaid.js.org/syntax/mindmap.html)、[Mermaid 字符实体](https://mermaid.js.org/syntax/flowchart.html#entity-codes-to-escape-characters)、[xml-js 官方 API](https://github.com/nashwaan/xml-js)。Mermaid 使用自身的数字实体语法；不能直接把所有 HTML 数字实体照搬过去。
