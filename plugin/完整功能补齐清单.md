## 依赖与模块边界

- 复用当前 SVG、Quill、xml-js、xlsx 和既有编辑器；不复制安装包内未公开的 VIP 模块。
- 用户已确认新增 roughjs 4.6.6 / rough-notation 0.5.1（MIT）处理手绘和圈画；版本固定，相关公开 API 已核查。
- 节点插件、画布插件、格式转换分别实施；主代理统一处理 Render/index、布局、前端、代码块和集成，避免并行改写同一文件。
- 多根数据继续使用 `root.data.freeNodeTrees` 数组，避免另造文件格式；原节点树保持根节点/子节点契约。

## 验证和交付

先对确定的缺口建立少量失败回归，随后实现；集中在隔离库检查交互、保存重开、撤销和导出。不建立按钮/主题/平台矩阵。依赖和跨模块行为必须验证实际接线，原有回归保留。

只有已集成并通过必要检查的构建才能安装 CMBK。安装前检查保存状态并备份个人插件文件；原参考插件与其 data.json 保持只读。最终逐行填写状态、证据及未完成风险，不用版本号代替验收结论。
