# 0.3.0 修复与验收清单

这是 0.3.0 的历史范围；HTML、Mermaid、OPML 已进入 [0.4.0 移植清单](0.4.0移植清单.md)，当前结果以验收记录最新章节为准。

本轮直接修复普通功能，复用参考源码，不接入账号、AI、图床、云服务和手机端。不把源码中存在入口当作功能已完成。

| 编号 | 实现范围 | 验收标准 |
| --- | --- | --- |
| R1 | Markdown 转换与预览命令 | 覆盖/副本两种转换可用；转换失败不留下半转换文件 |
| R2 | JSON/SMM 图片、SVG 透明、Markdown 标题层级 | 导出回调被等待；库内图片随数据导出；透明及层级参数实际生效 |
| R3 | 彩虹线、富文本链接、普通内链 | 正确调用当前引擎接口；关闭新窗口选项后点击无异常；编辑与重开保留链接 |
| R4 | 字体管理与默认字体 | 可添加字体并搜索；新图使用默认值；已有图显式应用且保留节点单独字体 |
| R5 | 模板、语言、公式、自动保存配置 | 配置有真实消费者；模板支持文件/目录；自动保存统一正整数 |
| R6 | 普通布局与节点操作 | 已支持的三个布局有入口；附件、标签筛选、限定搜索、向上同级、关联线显隐可用 |
| R7 | Markdown smm 代码块 | 可渲染、明确编辑和保存；高度/透明配置有效；冲突或多个相同块不会覆盖错误位置 |
| R8 | 多实例与宿主坐标 | 配置不串用 localStorage；触摸/浮层/编辑边界仅按实际缺口修复 |
| R9 | 集成与安装 | 必要回归、构建、隔离库检查；备份后更新 CMBK；构建文件哈希一致 |

必要测试限于数据安全和本轮确定的接口问题；交互集中在隔离库验证，不追加按钮矩阵或覆盖率工程。

暂未移植的增强引擎能力必须在交付时保留清单：手绘、动量、同级自动对齐、自由节点/多根、节点批注、专用节点连链、右鱼骨/表格布局、额外形状，以及 HTML/XLSX/FreeMind/Mermaid/OPML 导出和对应扩展导入。图片懒加载需独立验证后再承诺。个人分支不绑定原产品更新检查。

R1–R9 的普通功能与代表性场景已经闭环，实际命令和未穷举范围见 [验收记录](验收记录.md)。增强引擎和上述排除项未实现，不能按“参考插件全部功能完成”交付。构建已安装到 CMBK；本批源码一并纳入 0.4.0 交付提交，提交及远端发布状态以 Git 记录为准。
