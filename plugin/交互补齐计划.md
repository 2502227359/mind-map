## 真实调用与必要证据

- `editorModes` 接到 Edit 和 Contextmenu；`currentDocument` 同时用于保存协调器捕获、自动保存和模式切换。FocusSession 的纯数据合并回归覆盖兄弟/游离树/图像/位置/富文本版本。实机聚焦关闭后磁盘含 root06、sibling06、free06，重开后 child06 改动保留。
- `BlankMode` 接画布菜单和横幅；DOM 隐藏、逐个揭示、导出前后恢复、清理及原文不变由必要自动回归覆盖。实机显示序列为 hidden/hidden → 空/hidden → 空/空。
- `link-hover` 通过 editor-api 调用原生 hover-link。实机 source 为 personal-mindmap、sourcePath 为 0.6-交互.smm.md、目标为 0.6-普通笔记.md，原生弹层存在。
- `MarkdownMapPreviewView` 已注册视图和两条命令，Menus 提供两种入口。实机只读、尺寸占满面板、源文相同；源文件修改、改名、删除均刷新，删除后引擎已销毁。隐藏时不调用零尺寸 resize，重新显示后恢复。
- `NodeLinkSelect` 由 NodeFeatures 弹窗挂载；`TextEdit` 的 node_desc_dblclick 对应 SET_NODE_DESC；`NodeChatDialog` 由 Edit 挂载并接 chat_dialog_style/contextmenu，所有监听有注销。
- `FreeNode.setLayout` 接 Structure 的对话框；null 删除覆盖字段并继承主树，原有回归增加此边界及只读检查。
- `placeContextMenu/placeSubmenu` 接 Contextmenu。参考插件仅手机菜单滚动；本地原有桌面 overflow:auto、混用坐标和后代悬停规则共同造成故障。修复后桌面根菜单挂到 body，避开 Obsidian 叶片 contain:strict；各级固定定位并独立控制层级。
- 菜单原故障实机结果 pass:false、子菜单 right:1228 大于 viewport:1032；仅修方向仍不可点击，取消 overflow 后才可点击；更深层五个菜单全部显示。修复后二级 17 行与三级 10 行全部可点击、均在窗口内，悬停只显示对应分支。CDP 真实鼠标点击写入 number:{type:1,level:1}，菜单关闭。

集中回归 `npm --prefix web run test:obsidian`：77 项通过，0 失败；构建和 diff 检查通过。交付哈希、部署和残余边界见《验收记录.md》。项目根未采用 STATUS.md，不为本轮引入新约定。
