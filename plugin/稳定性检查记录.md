# 桌面稳定性与差异复核

日期：2026-10-30。基线：0efe883d，版本 0.6.0。用户授权一次有边界的参考差异复核与稳定性检查；不扩展 AI、账号/云服务、手机端、多语言或更新检查。

## 本轮验收边界

1. 菜单、工具栏和快捷键：核查真实入口与回调，区分已排除、等效实现、确认缺陷；不以安装包中的功能名推断遗漏。
2. 设置：核查用户可见选项的读取、保存和引擎消费链；不改参考插件的数据文件。
3. 同文件两个视图：干净视图接收外部更新；两份脏内容冲突时阻止覆盖，关闭时保留恢复副本。
4. 聚焦、撤销、外部变化：捕获始终是完整文档；退出和撤销不恢复过期快照；切换或关闭不遗留监听/定时器。

只在隔离库使用合成文档。确认问题先留失败信号，再修改；仅为真实逻辑缺陷增加必要回归，不增加按钮/主题矩阵。完成后记录实测结果、代码位置与未覆盖边界，实际修复通过后才更新 CMBK。
