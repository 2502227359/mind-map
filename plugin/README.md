# 个人思维导图

基于仓库内的 Simple mind map 引擎和原 Vue 界面开发。当前版本 `0.1.0`，只在 Windows、Obsidian 1.14.4 中验证，尚未安装到 CMBK。

## 构建

在仓库的 `web` 目录执行：

```powershell
npm ci --no-audit --no-fund
npm run build:obsidian
```

产物位于 `plugin/dist/`，包含 `main.js`、`styles.css`、`manifest.json` 和原项目许可证。构建复用现有锁文件及 Webpack、Vue 编译器、esbuild，不需要单独安装另一套工具链。所有导图引擎主入口及深层导入均解析到本仓库 `simple-mind-map/`。

必要验证命令：

```powershell
npm run test:obsidian
```

只有文档格式、保存时序和外部冲突三类测试，共 7 个用例。不提供按钮级自动化测试或覆盖率指标。

## 使用

隔离测试库位于 `C:/Users/86152/Documents/vscode files/mind-map/work/PersonalMindmap_Test`，已安装并启用 `personal-mindmap`，可直接试用。

正式安装时，把 `plugin/dist/` 中的文件复制到目标库 `.obsidian/plugins/personal-mindmap/`，再启用“个人思维导图”。不要覆盖已有 `simple-mind-map` 插件目录，也不要复制其 `data.json`。首次安装前保留笔记库备份。

主要命令：

- 新建思维导图：创建 `未命名导图.mindmap.md`，默认与当前笔记同目录。
- 用思维导图打开当前文件：打开本插件格式的 Markdown；普通笔记不会被转换。
- 保存当前导图：立即提交正在编辑的节点并保存。
- 将当前导图另存副本：保留当前原文件，创建唯一命名的新文件。
- 用 Markdown 打开当前导图：先保存，再切换到源码视图。

顶部复用原工具栏，右侧保留节点样式、基础样式、主题和结构面板，底部提供搜索、画布导航与缩放。节点快捷键沿用上游：Tab 插入子节点，Enter 插入同级节点，F2 编辑，Ctrl+Z 撤销，Ctrl+Y 重做，Ctrl+F 搜索，Ctrl+I 适应画布。仅活动导图处理快捷键。

超链接对话框中的“选择库内笔记”用于选择笔记。链接在新标签页打开，不替换正在编辑的导图；可保留 `#标题` 或 `#^区块` 子路径。外部链接仅支持 HTTP 和 HTTPS。

## 保存与恢复

文件内完整 JSON 是导图的唯一数据源，链接区和层级正文由它生成。直接修改正文不会同步成节点；受管区以外的个人说明和其他 frontmatter 会被保留。

内容变化默认防抖约 800 毫秒保存，连续编辑最长约 5 秒触发一次。节点、主题、结构、基础样式、视口及实际使用的编辑器配置会一起保存。打开和恢复文件不主动覆盖源数据。

保存前比较整份原文。检测到外部修改时，本地干净则重新加载；本地未保存则停止写入，显示冲突。此时可另存当前内存内容，或明确丢弃本地修改并重新加载。不能自动强制覆盖外部版本。

正常关闭时提交最后快照。原文件被删除或保存失败时，尝试在原目录生成带“恢复”的唯一副本；只有写入成功才显示恢复路径。原文件和恢复目录都不可写、强制结束进程或断电时，尚未落盘的数据不能保证恢复。

## 当前边界

- 同一导图只允许一个可写导图视图；已有其他 Markdown 编辑面时拒绝新增写入者。
- 两张不同导图可分别打开；后台零尺寸标签页延迟初始化，重新激活后恢复。
- 核心模式关闭富文本，避免上游 Quill 全局资源影响多视图；普通文字和字体样式仍可用。
- 不读取旧插件 `.smm.md`，不做 Markdown 正文双向同步或 AI 接入。
- 图片落库、导入导出和高级节点面板未作为核心版启用；已有直接可用的备注、标签、概要及关联线沿用上游能力。
- 目标笔记重命名后不自动改写全部节点链接；失效时重新选择目标。
- 自动打开使用公开工作区事件，没有修改 Obsidian 原型；未覆盖的打开路径可使用明确命令。
- 手机、macOS、Linux、独立弹出窗口和其他第三方插件组合尚未验证。
